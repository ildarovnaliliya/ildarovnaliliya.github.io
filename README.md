# Aliya & Liliy — лендинг

Готовый статический сайт. HTML + CSS + JavaScript, без сборки, npm, сервера и внешних библиотек. Работает в подпапке проекта GitHub/GitLab Pages. Все ресурсы локальные.

## Посмотреть
Распакуйте ZIP и откройте `index.html` в браузере. Для копирования браузер может потребовать HTTPS: при локальном просмотре есть запасной вариант — выделение текста для ручного копирования.

## GitHub Pages
1. Создайте репозиторий на GitHub.
2. Загрузите СОДЕРЖИМОЕ архива в корень репозитория: `index.html` должен лежать в корне, а не внутри дополнительной папки. Папку `assets` загрузите целиком.
3. Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите основную ветку (обычно main) и папку `/ (root)`, сохраните.
5. После завершения публикации откройте адрес, который покажет GitHub.
Для загрузки через веб-интерфейс достаточно публичных файлов. `.nojekyll` отключает Jekyll; без него сайт также не требует специальной сборки.

## GitLab Pages
1. Создайте проект и загрузите файлы в корень репозитория вместе со скрытым файлом `.gitlab-ci.yml`.
2. Конфигурация рассчитана на современный GitLab.com / GitLab 17.9+. На старой self-hosted версии синтаксис Pages может отличаться.
3. Сделайте commit в основную ветку. Дождитесь успешного pipeline (проекту нужен доступный runner).
4. Откройте Deploy → Pages и используйте выданный GitLab адрес. Проверьте настройки публичного доступа, если сайт должен быть виден без входа.

## Что где менять
- `config.js` — контакты и адрес. Поле brand зарезервировано; логотип и заголовки меняются в HTML.
- `catalog.js` — 31 позиция, цены, категории, объёмы. После изменения обновите также резервный прайс `price.html`.
- `index.html` — текст, имена специалистов, структура страницы.
- `style.css` — цвета, шрифты, адаптивная вёрстка.
- `app.js` — категории, мобильное меню, диалог записи и копирование.
- `price.html` — полный прайс, работает без JavaScript.
- `assets/studio-logo.jpg` — предоставленная эмблема на первом экране.
- `assets/aliya.jpg`, `assets/liliya.jpg` — портреты специалистов. Кадрирование сделано в CSS через object-fit; исходные фото сохранены без изменений.

## Запись и персональные данные
Формы отправки и базы данных нет. Сайт не собирает имя и телефон, не использует аналитику, cookies и внешние шрифты. Сообщение отправляет сам посетитель в выбранном мессенджере; Telegram и Instagram открывают аккаунты студии, WhatsApp — чат с подготовленным текстом, кнопка звонка использует tel:. На телефоне ссылки передаются приложению, если оно установлено и система разрешает открытие; иначе открывается веб-версия или системный диалог. Для Instagram при необходимости нажмите «Написать» в профиле; текст можно скопировать из диалога сайта. Успех записи сайт не имитирует. При подключении внешнего сервиса его правила обработки данных нужно учитывать отдельно.

## Проверка
Проверены синтаксис JavaScript, количество и точность переноса позиций, локальные ссылки и структура ZIP. Проверка отображения в реальном браузере в этой среде не выполнялась. Перед публичным запуском проверьте сайт на телефоне и компьютере и пройдите путь записи. Фактическое открытие внешних приложений зависит от устройства и не проверено в этой среде.

Структура вдохновлена предоставленным референсом drkorotaeva.ru. Тексты, фотографии, отзывы и сведения о квалификации конкурентки не скопированы. Цены — только из ваших пяти изображений.

Официальные инструкции: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site и https://docs.gitlab.com/user/project/pages/introduction/
